# results/

Store reproducible summaries, tables, and paper-facing outputs here.

Suggested subdirectories:
- `version0_shared_unit/`
- `stage2_analysis/`
- `stage3_light_interaction/`
- `paper_tables/`
- `paper_figures/`

Every result summary should state:
- dataset view
- folds used
- protocol name
- comparison target
- creation time
- source run directories or files
